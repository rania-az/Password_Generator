# Password Generator
A simple password generator developed in Python as a beginner programming project.

## Description
This program generates a random password based on the length selected by the user.
The password contains uppercase and lowercase letters, numbers, and special characters.

## Features
- User-defined password length
- Random password generation
- Uppercase and lowercase letters
- Numbers and special characters
- Validation of password length

## Technologies
- Python
- Visual Studio Code

## Concepts Practiced
- Variables
- User input (`input()`)
- Type conversion (`int()`)
- Conditional statements (`if`, `else`)
- Loops (`for`)
- Random module (`random`)
- String module (`string`)

## How to Run
1. Open the project in Visual Studio Code.
2. Open the `main.py` file.
3. Click the **Run** button to execute the program.
4. Enter the desired password length.
